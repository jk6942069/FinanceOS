System Design

How the System Works

A clean three-layer architecture: owner enters data, the engine runs intelligence, users see only the output. No spreadsheets. No AI visible. No complexity exposed.

✏️
Data Layer (Owner Input)
  • Monthly financial form
  • Bank balance fields
  • Revenue breakdown
  • COGS & OPEX entries
  • AR aging entries
  • Upcoming obligations
  • 3-month history
→
⬡
Intelligence Engine (Hidden)
  • Cash runway model
  • Payroll risk calc
  • Margin compression
  • Revenue trend signal
  • Health score (0–100)
  • Brief generation API
  • Alert trigger logic
→
📊
User Output Layer (What Clients See)
  • Health score dashboard
  • 4 KPI cards
  • Ranked decision list
  • Revenue trend chart
  • AR aging panel
  • Weekly brief PDF
  • Email digest (weekly)
🔒

The AI is never visible to end users

The intelligence engine runs server-side. Users interact with a standard web application — login, dashboard, reports. The brief reads as the product's own analysis. There is no "powered by AI" disclosure in the user flow. Your brand is the product.

Implementation

No-Code to Full-Code Stack

Pick the layer that matches your current technical capability. Start at Layer 1 today. Graduate as you grow.

⚡ Layer 1 — Today

Zero code. Manual but real. Run this exact system with your current tools for your first clients.

Excel / Google Sheets Claude.ai Email PDF export

🔧 Layer 2 — Month 2

No-code app. Build a real product your clients log into without writing a line of code.

Bubble.io Airtable Zapier Memberstack Anthropic API

🚀 Layer 3 — Month 6+

Production SaaS. Full data integrations, bank sync, automated ingestion, mobile.

React + TypeScript Node.js PostgreSQL Plaid API Claude API AWS

👤 Auth & Users

Each client gets their own secure login. Data is isolated per business. No client sees another's data.

Memberstack (L2) Auth0 (L3) JWT tokens Row-level security

🤖 Intelligence Engine

The calculation layer and brief generation — runs server-side, invisible to end users.

Claude API (Sonnet) Zapier webhook (L2) Node.js cron (L3) Structured prompt

📧 Delivery

Weekly brief lands in client email automatically. No client needs to log in to get their report.

SendGrid Postmark HTML email template PDF attachment
